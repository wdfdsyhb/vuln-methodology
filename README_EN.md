# vuln-methodology · Vulnerability Hunting Methodology

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE) ![ZCode Skill](https://img.shields.io/badge/AI-ZCode_Skill-purple)

> Ask "how do I hunt IDOR" and get the full playbook: 11 vulnerability classes, each with methodology steps, payload directions, real cases and tool lists.

## Installation

Drop this repository into your AI coding tool's skills directory:

```
~/.zcode/skills/vuln-methodology/     # ZCode
```

Trigger words: `怎么挖XX漏洞` (how to hunt X) / `漏洞方法论` (vulnerability methodology)

## Covered Vulnerability Classes

IDOR / broken authorization, authentication bypass, logic flaws, SQL injection, XSS, SSRF, file upload, template injection, deserialization, CSRF, open redirect — each with methodology steps, payload directions, real cases and matching tools.

## Companion

- `references/` directory: detailed references and tool lists for each class
- Pairs with [src-hunter-enhanced](https://github.com/wdfdsyhb/src-hunter-enhanced): this repo teaches "how to think", src-hunter gives "how to strike"
