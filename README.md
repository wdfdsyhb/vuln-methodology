# vuln-methodology

漏洞挖掘方法论 **Agent 技能**：11 种漏洞类型的完整方法论 + 真实案例 + 40 工具清单。

## 安装

把本仓库放进你的 AI 编码工具技能目录：

```
~/.zcode/skills/vuln-methodology/     # ZCode
```

触发词：`怎么挖XX漏洞` / `漏洞方法论`

## 覆盖的漏洞类型

IDOR/越权、认证绕过、逻辑漏洞、SQL 注入、XSS、SSRF、文件上传、模板注入、反序列化、CSRF、开放重定向——每类含方法论步骤、payload 方向、真实案例与对应工具。

## 配套

- `references/` 目录：各类漏洞的详细参考与工具清单
- 与 [src-hunter-enhanced](https://github.com/wdfdsyhb/src-hunter-enhanced) 配合：本仓库讲「怎么想」，src-hunter 给「怎么打」
