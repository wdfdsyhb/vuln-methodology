# vuln-methodology · 漏洞挖掘方法论库

[![CI](https://github.com/wdfdsyhb/vuln-methodology/actions/workflows/lint.yml/badge.svg)](https://github.com/wdfdsyhb/vuln-methodology/actions/workflows/lint.yml) [![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE) ![ZCode Skill](https://img.shields.io/badge/AI-ZCode_Skill-purple)

> 问一句「怎么挖 IDOR」，拿到完整打法：11 种漏洞类型，每类配方法论步骤、payload 方向、真实案例和工具清单。
>
> English: Ask "how do I hunt IDOR" and get the full playbook — 11 vulnerability classes, each with methodology steps, payload directions, real cases and tool lists.

## 安装

把本仓库放进你的 AI 编码工具技能目录：

```
~/.zcode/skills/vuln-methodology/     # ZCode
```

触发词：`怎么挖XX漏洞` / `漏洞方法论`

## 覆盖的漏洞类型

IDOR/越权、认证绕过、逻辑漏洞、SQL 注入、XSS、SSRF、文件上传、模板注入、反序列化、CSRF、开放重定向——每类含方法论步骤、payload 方向、真实案例与对应工具。

## 配套

- `references/` 目录：各类漏洞的详细参考与工具清单
- 与 [src-hunter-enhanced](https://github.com/wdfdsyhb/src-hunter-enhanced) 配合：本仓库讲「怎么想」，src-hunter 给「怎么打」
